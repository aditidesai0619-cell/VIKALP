WFS STATUS
The service's dedicated WFS endpoint was tested directly
(service=WFS&request=GetCapabilities at both /bhuvan/wfs and
/bhuvan/ows) and returned the explicit server error "Service WFS is
disabled" both times — confirmed, not assumed. No vector/GeoJSON bulk
download endpoint is available for these layers. GetFeatureInfo (a
point-query mechanism, not bulk export) was the only working query
interface found.
